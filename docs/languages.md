# 界面与人物台词语言

主页右上角的「文 / A」打开语言设置。界面与人物台词分别选择中文、日语或英语，初始值均为中文；无需重新加载页面。设置保存为 `omn_terminal_language_v1`，加入既有云同步，伴侣读取同一个偏好键。

界面只翻译代码中明确标记的程序标签、提示与占位文字。记录正文、历史留言、用户自定义名称、输入值、选项底层值和已有数据键不翻译、不迁移。没有显式 value 的程序选项在标记时保留原 value；折叠栏继续按原标题生成持久化键。

`app-language-data.js` 保存界面对照，`app-language.js` 处理设置及标记更新。动态数据表达式不纳入界面翻译。当前固定台词与睡眠描述的中日英对照在 `dialogue-translations.mjs`；自定义导入内容保留原文。

`language-core.mjs` 为生成端提供语言约束。新状态台词、世界片段及伴侣回复的请求携带独立的 dialogue language，状态时间线与人物事实仍由原引擎决定。非中文生成使用带语言的设定修订值以区分缓存；切换语言后，旧请求即使稍后完成，也不能写回当前台词池。结果仍作为历史保留。世界片段与旧批次的结果附带可选 language 标记；不含标记的旧内容按中文读取。中文原有请求兼容。

界面版本：`20261125-language1`。Windows 原生核心仍为 0.1.7；不改变签名更新包。没有数据库结构迁移，没有修改认证、人物设定、排班、经济规则或原有档案内容。
