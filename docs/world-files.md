# Jane 世界档案

WORLD FILES 是 Jane 各世界线的长期资料入口。它使用饮食／账本现有的五个世界 ID，不重写首页场景，也不搬运各模块存档。

- META世界：`meta`
- 萨克门托：`sacramento`（CBI 的叙事对应）
- 古代后宫：`palace`
- 狐狸AU：`fox`
- Leverage AU：`heist`

夹缝空间仍由首页世界切换与原 `story.html` 章节保存承接，本页不列入世界选择。

## 编辑与保存

`world-files.html` 提供世界设定、剧情档案、日常片段三个栏目。世界设定可编辑身份、当前进度、关系、记忆连续性和写作偏好；萨克门托以已确认的 META／2006 与十年关系作为初始内容，其余世界不预设未确认剧情。

剧情档案支持新增、修改、选填发生时间、单独选择是否用于生成，以及移除／恢复。生成片段不会自动改动设定，只有用户收进剧情档案并保存后才成为后续依据。原 CBI 案宗、人物和合并时间轴继续在 `cbi.html`，从萨克门托页进入。

档案保存在 `jane_world_files_v1`，随现有账号同步、历史保护和完整备份保存；备份页也列出这个模块。保存按当前世界合并最新本地资料，保留其他世界。编辑草稿按账号与世界保存在当前浏览器会话中；同步失败不关闭编辑器，重试新记录沿用同一 ID，避免重复建档。新格式或损坏记录不在打开页面时自动重写。

单个设定字段最多20000字符；单条剧情正文最多50000字符，每世界最多1000条记录（含可恢复的已移除项）。生成上下文超过120000字符时提示减少用于生成的旧条目，不截断或删除已保存正文。

## 生成

当前世界的设定和勾选的剧情随请求提供给 Claude，不要求 Claude自行登录应用读取资料。萨克门托另参考既有 CBI 人物前史、时间轴及案件叙述字段；不序列化整份 `cbi_db`，不传资金、排班或现实记录。世界之间不自动交换身份、剧情和记忆。

编辑后下一批办公室／居家台词和本世界日常使用新版本。日常片段采用 `jane-world-lines` 格式，由同一已有 Claude 云端任务生成，保留在账号的运行记录。饮食／账本当前可见世界页按06／11／17／22日本时间准备；无设定的新世界不启动生成。WORLD FILES 提供可选的“生成一段日常”。已经配置的连接继续使用，无须反复替换任务说明。

所有新生成均绑定世界和设定摘要版本，旧批次保留但标为旧版。主页现有工位／居家动作、实际排班、睡眠和动作时长不交给模型决定。
